📖 About
The OSINT Framework is a powerful, categorized collection of tools and methods for open-source intelligence gathering. This repository organizes everything into clean categories so researchers, investigators, penetration testers, and analysts can uncover critical information — fast and efficiently.
> ⚠️ \*\*Disclaimer:\*\* These tools are listed for legal, ethical purposes only — security research, journalism, threat intelligence, and authorized investigations. Always comply with local laws, platform Terms of Service, and obtain proper authorization before conducting any investigation.
